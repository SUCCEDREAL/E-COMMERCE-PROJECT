# 🛍️ E-Commerce Website

A modern frontend e-commerce web application built with **React.js** and **Vite**. The application allows users to browse products, view product details, add items to the cart, and enjoy a smooth shopping experience. This project focuses on frontend development and consumes data from a public API.

---

## 📖 Overview

This project demonstrates the core features of an e-commerce website using React. It includes dynamic product rendering, shopping cart functionality.

---

## ✨ Features

- 🏠 Home page
- 🛒 Shopping cart
- 📦 Product listing
- ➕ Add products to cart
- 🔢 Cart item count displayed in the navigation bar
- 💾 Cart data stored using Local Storage
- 👥 About Us
- 👤 User Signup page
- 🔐 User Login page
- ⏳ Loading spinner while fetching products
- ⚠️ Error handling for failed API requests

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/SUCCEDREAL/E-COMMERCE-PROJECT.git
````

### Install dependencies

- react-router-dom
- react-router
- react-loader-spinner
- react icons

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will run locally on:

```
http://localhost:5173
```
